# Loobyt — extensão Tachimanga

Extensão em desenvolvimento para ler mangás do Loobyt/WiComix no Tachimanga.

- Idioma: Português (Brasil)
- Catálogo: todos os títulos disponibilizados pela fonte
- Recursos planejados: busca, detalhes, capítulos e páginas de leitura

O pacote instalável e o índice do Tachimanga só serão publicados depois de validar a implementação e compilar o projeto.
